# 运行并部署你的应用

本项目包含了在本地运行应用所需的一切配置。


[English](./README.md) | [简体中文](./README_zh-CN.md)

## 功能特性

- **个性化学习路径生成**：根据你的学习目标、水平和时间，AI 自动为你量身定制专属课程大纲。
- **智能内容创作**：实时生成高质量的学习教材，支持 Markdown 格式，图文并茂。
- **AI 随身导师**：内置智能对话助手，随时解答学习过程中的疑惑，提供针对性指导。
- **自动测验评估**：每个模块学习结束后，自动生成测验题，帮助你巩固知识点并评估学习效果。
- **多模型支持**：支持 Google Gemini 和 阿里云百炼 (Qwen) 双引擎，可自由切换。
- **学习进度追踪**：自动保存学习进度和测验成绩，随时掌握自己的成长轨迹。

## 本地运行指南

**前置要求：** 需要安装 [Node.js](https://nodejs.org/) 环境。

### 1. 安装依赖

在终端中运行以下命令安装项目所需的依赖包：

```bash
npm install
```

### 2. 配置环境变量

在项目根目录下创建一个名为 `.env.local` 的文件，并将你的 Gemini API 密钥配置在其中：

```env
GEMINI_API_KEY=你的_API_密钥_这里
```

> **注意**：不要将你的 API 密钥提交到版本控制系统中（`.env.local` 文件默认已被忽略）。

### 3. 启动应用

运行以下命令启动本地开发服务器：

```bash
npm run dev
```

启动后，通常可以通过浏览器访问 `http://localhost:5173` 来查看应用。
